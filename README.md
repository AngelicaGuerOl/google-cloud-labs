# Google Cloud Engineering Certificate — Hands-On Labs

A collection of hands-on labs completed as part of the **Google Cloud Engineering Certificate**.

This repository documents practical exercises covering Google Cloud infrastructure, networking, compute, storage, databases, security, and application deployment.

The purpose of this repository is to document the progression of practical skills developed throughout the certificate through real Google Cloud configurations, command-line operations, troubleshooting, and implementation evidence.

---

## ☁️ Certificate Topics

The labs in this repository cover different areas of Google Cloud engineering, including:

- Cloud infrastructure fundamentals
- Virtual Private Cloud (VPC) networking
- Subnets, routes, and firewall rules
- Compute Engine and virtual machines
- Linux and server configuration
- Cloud Storage
- Cloud SQL and relational databases
- IAM and access control
- Cloud security fundamentals
- Application deployment
- Networking and connectivity
- Google Cloud command-line tools
- Troubleshooting and cloud architecture
